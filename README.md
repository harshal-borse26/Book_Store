# Book Store Application

A full-stack bookstore application built using:

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary

## Features

- User Registration
- User Login
- JWT Authentication
- Role Based Authorization
- Add Books (Admin)
- Upload Book Images
- Browse Books
- Book Details
- Buy Books
- Order History



## Installation

### Backend

npm install
npm start

### Frontend

cd frontend
npm install
npm run dev
